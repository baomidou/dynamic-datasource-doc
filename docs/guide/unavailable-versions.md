# 不可用版本

某些版本存在已知问题，强烈不建议使用。新项目请直接使用最新版本。

## 不建议使用的版本

| 版本 | 问题 |
| :--- | :--- |
| v4.0.0 | 强行依赖 MyBatis 等。 |
| v3.6.0 / v3.6.1 | `@DS("#header.xx")` 动态解析有问题，未用到则无影响。 |
| v3.3.3 | 严重 BUG：Advisor 启动失败，导致无法切换数据源。 |
| v3.3.0 | 打包后启动强制依赖 Seata。 |
| v3.1.0 | 使用 `NamedInheritableThreadLocal`，高并发下切换数据源失败。 |
| v2.3.3 | 嵌套切换数据源会回到主数据源。 |
| v2.3.2 / v2.3.1 / v2.2.2 | 存在已无法定位的 BUG，不建议使用。 |

升级建议见[版本记录与选择建议](/docs/guide/version-history)。
